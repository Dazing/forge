# forge INBOX — process-learning inbox

This is the inbox for **process / framework lessons** about forge itself — things learned
while *using* the loop on real products that should change the loop, the commands, the
template, or an ADR here.

`/forge:compound` routes learnings by scope: project conventions go to a product's own
`CLAUDE.md`, significant product decisions become that product's ADRs, and lessons about
**the framework** land here. Items accumulate during the week and are batch-applied to the
plugin deliberately — curation is a human act, and applying every stray thought live would
churn the framework faster than it stabilizes.

## How to use

- One bullet per lesson. Note the date and, if useful, the product/session it came from.
- Keep it raw — this is a capture buffer, not a polished doc. Triage happens on apply.
- When you apply an item (edit a command, the template, or write an ADR), delete it here.
