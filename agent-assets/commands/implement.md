# implement

Implement a single bounded change from an approved plan.

## Steps
1. Read the approved plan and the issue.
2. Make the minimal, conventional change the plan calls for.
3. Keep edits inside the expected paths. Explain every unexpected path.
4. Run the repository checks and record evidence for each acceptance
   criterion.

## Output
The structured implementation result that conforms to
`schemas/implementation.schema.json`.
